What is HTML?

HTML (Hyper Text Markup Language) is used to create the structure of web pages.

Basic Structure

<!DOCTYPE html>
<html>
<head></head>
<body>Hello</body>
</html>

Important Tags

  • <h1> → Heading
  • <p> → Paragraph
  • <a> → Link
  • <img> → Image
  • <header> → header

Example

<h1>Welcome</h1>

Uses of HTML

  • Create web pages
  • Structure content
  • Embed images/videos
