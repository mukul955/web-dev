What is CSS?

CSS (Cascading Style Sheets) is used to design and style web pages. It controls colors, layout, spacing, and fonts.

Why CSS is Important

  • Makes website attractive
  • Separates design from HTML
  • Improves user experience

CSS Syntax

selector {
property: value;
}

Example

h1 {
color: blue;
font-size: 30px;
}

Types of CSS

  • Inline CSS
  • Internal CSS
  • External CSS

Selectors

  • Element → h1, p
  • Class → .box
  • ID → #main

Box Model

  • Content
  • Padding
  • Border
  • Margin

Common Properties

  • color
  • background
  • margin
  • padding
  • border
